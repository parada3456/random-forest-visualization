Random Forest, Step by Step

Many deliberately noisy decision trees, averaged, make one stable predictor. Build a dataset, then grow the forest one tree at a time.

A random forest grows many decision trees, each on a bootstrap-resampled copy of the data, and lets every split consider only a random subset of features. Averaging their votes turns a flock of overfit, high-variance trees into one stable predictor.

The dashed outline is the convex hull of your training points; the darkened area outside it is extrapolation the forest was never trained on. ⓘEvery pixel is run through all trees built so far; each tree casts one vote for a class, and the pixel is shaded with whichever class wins the most votes. Outside the dashed hull, no bootstrap sample ever placed a point nearby — the forest's splits there are guesses, not evidence — so that region is dimmed ~40% as a trust cue.
